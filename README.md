#  Skill.AI Training

. Modern Full Stack EdTech Platform built with React, Node.js, Express, MongoDB and Razorpay.

---

# About

Skill.AI Training is a modern online learning platform where students can enroll in courses, make secure online payments, track their learning progress and receive certificates.

This project is currently under active development.

---

# Features

- 🔐 Secure Login & Registration
- 🔑 JWT Authentication
- 👨‍🎓 Student Dashboard
- 👨‍🏫 Faculty Dashboard
- 👨‍💼 Admin Dashboard
- 📚 Course Management
- 💳 Razorpay Payment Gateway
- 📈 Student Progress Tracking
- 📜 Certificate Generation
- 📱 Fully Responsive Design

#  Installation

Clone Repository

```bash
git clone https://github.com/deepakjangir12345/Skill-AI-Training.git
```

Install Dependencies

```bash
npm install
```

Run Backend

```bash
npm run server
```

Run Frontend

```bash
npm run dev
```
